# 数据层：Agent 操作警告

**不要因为发现此目录就直接下载、批量解析或改写数据。先确认用户任务确实需要，并阅读根目录的 `MAINTENANCE.md`。**

## 操作边界

- 本目录的 JSON / JS 是 Git LFS 托管的生成数据，不是普通源代码。Git 中看到的文件可能只是 LFS 指针；不要把指针当成数据解析。
- 用户要求图鉴与头像只存远程，本地只保留代码与用户表情包。禁止默认运行 `git lfs pull`、取消稀疏检出，或把数据写入工作区、临时目录、下载缓存。
- 不要为了了解项目而读取整份图鉴、输出完整数据、遍历全部头像，或把大量记录塞进上下文。优先读文档、脚本与合成测试；确有必要时，只在内存中读取任务相关的最少字段，输出摘要。
- 不要手工修改生成文件、重新编号、删除来源暂时缺失的精灵，或根据图鉴顺序猜测进化链。维护数据统一使用根目录 `maintain-data.ps1` / `maintain-data.py`。
- 维护脚本默认预览；只有用户授权发布时才使用 `--publish`。不要强推，也不要把凭据、签名链接或完整网络响应打印到日志。
- WIKI 访问受限时停止请求，不反复重试或绕过防护。浏览器手动导入流程见维护说明。缺少链上成员时先发布已校验精灵，保留进化链待补；不要编造缺失资料。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `pets.json` | 图鉴与六维、属性、特性、头像路径；保留既有精灵序号 |
| `pets.js` | 图鉴的兼容生成版本，不应与 JSON 独立编辑 |
| `evolutions.json` | WIKI 明确进化链映射；未核实不等于最低阶 |

头像位于远程 `assets/`，同样受上述边界约束。本 README 是普通 Git 文本，不需要 LFS 下载即可阅读。
