# 月牙雪熊 · 先发制人斩杀计算台

直接双击 `dist/月牙雪熊斩杀计算器.html` 即可使用。此文件已内置全部图片、样式、数据和脚本，可单独复制分享；无需服务器或联网。浏览器可能限制 file:// 下的本地存储，可使用 JSON 导入导出。

测试版包含六只精灵：月牙雪熊、火神、水灵、魔力猫、迪莫、雪影娃娃。双方六维可修改性格，个体箭头仅在 0、42、48、54、60 五档间移动，实际面板自动计算且只读。旧配置导入时个体归入最近合法档位（等距取较低档），移除手动面板覆盖；冻结超过 20 层时限为 20 层。

运行 `node engine.test.cjs` 检查计算核心。运行 `node build.mjs` 重新打包；首次构建会下载六张 BWIKI 图片，此后使用 assets 本地缓存。源代码 index.html 也可在完成构建后直接打开。

## 模型边界

个体默认全部0；向下调整按60→54→48→42→0循环，0再减回到60；上调到60时停止。已有保存配置保留其设定，重置或未保存时使用全0默认值。三张状态图片均在页面按1:1比例拉伸显示，源图片不改动。

Git LFS 管理所有 JPG/PNG 图片、内嵌资源 assets.js 和 dist 离线 HTML；源码与说明保留普通 Git 文本。克隆后执行 `git lfs pull` 获取完整大文件，或用本地素材执行 `node build.mjs` 重建。远程上传需要配置 Git 远程及其 LFS 服务。

性格在六维表内用增益、减益两列按钮选择；每列最多一项，再次点击取消。同一能力不能同时增益与减益，选中另一列会清除冲突项。支持只选增益或只选减益，旧性格配置自动转换。斩杀数字右侧按结果显示用户图片：可斩杀（含已倒下）为先发拿下，否则攻击后剩余可用生命（红段）低于最大生命5%为大发雷霆，等于或高于5%为冰点你咯。使用真实比例，不用进位后的显示百分比判断。

- 种族与培养换算、37/41 伤害系数、星陨威力、属性倍率来自 https://lovepvp.top ，2026-09-13 核对。不是官方实测保证。
- 月牙雪糕与先发制人描述参考 https://wiki.biligame.com/nrc/月牙雪熊 和 https://wiki.biligame.com/nrc/先发制人 。
- 本次按用户提供的公式：技能伤害 = floor(攻击/防御 × 37/41 × max(0, 技能威力×应对倍率+威力加成) × 能力等级 × 本系 × 克制 × 其他影响 × (1−减伤) × 其他免伤)。先发制人威力55，应对倍率与本系均为1。
- 星陨印记伤害 = floor(攻击/防御 × 37/41 × max(0, 印记威力+威力加成) × 能力等级 × 克制 × 其他影响 × (1−减伤) × 其他免伤)，只不乘本系加成；零层印记不触发，威力加成每级10点。印记威力保持 n²+24n−24（0层为0）。
- 能力倍率 = (1+攻击提升+防御降低)/(1+攻击降低+防御提升)。物攻、物防、威力三个等级均为整数 −99～+99；攻防每层10%，威力每层10点。同方向项相加，不按两个独立倍率相乘。
- 拖条、数字输入、归零与配置存储联动；旧配置缺失等级时按0处理。威力变为负数时暂截为0，星陨继续独立计算，此下限为实现约定。
- 高级修正对应其他影响；当前只有应对防御减伤，其他免伤暂固定1，未来新增多个免伤按剩余伤害比例连乘。
- 目标特性仅展示，未自动模拟条件触发。换人、场下冻结、其他印记、天气、护盾及特殊触发链未自动模拟。保命开关将攻击后的生命保留为至少 1，但仍检查冻结死亡线。
- 六维是 lovepvp PVP 口径，保留原培养换算系数，未提供任意等级成长公式。个体五档与冻结死亡规则按用户本次提供的规则更新。
- 冻结上限 20，每层对应最大生命的 5%；剩余生命小于等于冻结生命线则死亡。冻结血量按 floor(最大生命 × 层数 / 20) 对总量一次向下取整。当前生命百分比向上取整，血量拖条和左右加减按 1 HP 调整。
- “最低冻结”是保持已有星陨不变时需要的总冻结层数，在 0–20 层内枚举，同时考虑伤害与冻结死亡线。已有星陨与冻结转化后的总星陨均限制为 99 层。
- 血条自左至右为冰蓝冻结、红色剩余可用生命、淡紫星陨伤害、灰色先发伤害、空白已掉生命。伤害段只展示当前可用生命范围内的有效部分；先发先消耗可用生命，随后星陨。02 斩杀线数值显示完整理论伤害 + 冻结血量，分项另列。冻结段最多占当前生命，真实冻结阈值单独标注。
- 当前模型不含随机波动、命中、能量是否足够与行动先后判定。伤害足够仅代表当前输入条件下数值足够。

## 冻结取整争议（尚未实测）

用户推理：若最大生命为 510，5% 是 25.5 HP；若冻结向上取整为 26 HP，当前 26 HP 的百分比向上取整为 6%，就可能显示 6% 生命却被 1 层冻结击败。根据用户要求暂采用总冻结量向下取整（该例为 25 HP），百分比向上取整。此推理不能代替游戏实测，也没有确认游戏内部是否保留小数。

2026-09-13 搜索并核对 [WIKI 雪怪的冻结说明](https://wiki.biligame.com/nrc/雪怪)：描述每层冻结 5%，当前生命“低于”冻结比例则力竭，未说明取整，也未明确等号边界。工具暂保留用户要求的 ≤ 判定，取整与等号均待实测。对整数生命，原先直接比较精确阈值的 ≤ 判定与 floor 阈值的 ≤ 判定等价；本次主要修正冻结血量显示、血条分段和斩杀线合计。
