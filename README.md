# 月牙雪熊斩杀计算器 · 远程数据版

打开 dist/月牙雪熊斩杀计算器.html，必须联网。网页只内嵌三张用户表情包。593条图鉴从 GitHub LFS 的实际下载地址加载，头像仅在需要时请求仓库的WebP。fetch使用cache:no-store，不使用IndexedDB、Service Worker或localStorage存储图鉴、头像或配置；关闭页面释放内存。浏览器内部内存、系统交换区不能视为完全不产生任何临时字节，但工作区不保留这些素材。

## 本地与仓库

assets/、data/只保存在远程；本地通过sparse-checkout排除，Git LFS skip-smudge禁用自动下载。旧LFS对象缓存清理后可从远程重新获取。不要运行git lfs pull或关闭稀疏检出，否则会重新下载资料。构建命令node build.mjs只读取代码与三张表情包。

## 萌化

每点一次退化上一阶，只替换种族值，保持所选精灵原属性、特性。除厄清除所有萌化，恢复原种族值。当前血量按变化前比例换算并向上取整；满血保持满血。进化链由WIKI网页明确节点构建；未核实条目禁用萌化，多个前置候选提供分支选择，不凭图鉴顺序猜测。

## 计算规则

个体档位0/42/48/54/60，默认全0，加减均循环。当前与剩余生命百分比向上取整。冻结20层上限，每层5%最大生命，总冻结血量向下取整，生命≤冻结线死亡（取整与等号边界为用户指定的待实测规则）。星陨合计上限99。

能力倍率=(1+攻击提升+防御降低)/(1+攻击降低+防御提升)，攻防每级10%；威力每级10点，范围均±99。技能与星陨均乘面板攻防比、37/41、能力倍率、克制、其他影响及应对防御减伤；星陨威力n²+24n−24再加威力加成，不乘本系。零层星陨不触发，负威力截为0，伤害分别向下取整。特性仅展示，未自动模拟所有特性免伤。
