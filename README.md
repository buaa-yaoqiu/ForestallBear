# 月牙雪熊斩杀计算器 · 远程数据版

打开 dist/月牙雪熊斩杀计算器.html，必须联网。网页只内嵌四张用户表情包。图鉴从 GitHub LFS 的实际下载地址加载，头像仅在需要时请求仓库的 WebP 或新增 PNG。fetch使用cache:no-store，不使用IndexedDB、Service Worker或localStorage存储图鉴、头像或配置；关闭页面释放内存。浏览器内部内存、系统交换区不能视为完全不产生任何临时字节，但工作区不保留这些素材。

## 本地与仓库

assets/、data/只保存在远程；本地通过sparse-checkout排除，Git LFS skip-smudge禁用自动下载。旧LFS对象缓存清理后可从远程重新获取。不要运行git lfs pull或关闭稀疏检出，否则会重新下载资料。构建命令node build.mjs只读取代码与四张表情包。

## 维护数据

使用 `./maintain-data.ps1` 添加／更新精灵、上传新头像、补充 WIKI 进化链，默认预览，添加 `--publish` 才发布。整个流程在内存中进行，不创建本地图鉴或头像文件。首次配置、常用命令和浏览器手动导入见 [维护说明](MAINTENANCE.md)。不要使用会写入本地数据的旧 `sync-data.mjs`、`thumbnails.py`。

## 萌化

2026-09-14 已按WIKI页面进化链栏（含多分支及形态链接）核实96个当前图鉴条目，其中69个有上一阶。其余因站点访问防护中断，仍未核实，不能视为最低阶。读取结果经 evolution-import.mjs 的内存桥直接上传远程LFS，不产生本地数据文件。WIKI当前站点声明对可授权文字采用CC BY-SA 4.0，游戏图片版权归原权利人。

萌化与除厄为特性、种族总和右侧的小按钮。萌化中的头像右上角显示心形标记，不显示额外种族值/特性保留说明。椰浆布丁（冰布丁）始终使用用户提供的“可恶的冰布丁.jpg”，优先于斩杀状态。所有表情包按1:1拉伸。

每点一次退化上一阶，只替换种族值，保持所选精灵原属性、特性。除厄清除所有萌化，恢复原种族值。当前血量按变化前比例换算并向上取整；满血保持满血。进化链由WIKI网页明确节点构建；未核实条目禁用萌化，多个前置候选提供分支选择，不凭图鉴顺序猜测。

## 计算规则

个体档位0/42/48/54/60，默认全0，加减均循环。当前与剩余生命百分比向上取整。冻结20层上限，每层5%最大生命，总冻结血量向下取整，生命≤冻结线死亡（取整与等号边界为用户指定的待实测规则）。星陨合计上限99。

能力倍率=(1+攻击提升+防御降低)/(1+攻击降低+防御提升)，攻防每级10%；威力每级10点，范围均±99。技能与星陨均乘面板攻防比、37/41、能力倍率、克制、其他影响及应对防御减伤；星陨威力n²+24n−24再加威力加成，不乘本系。零层星陨不触发，负威力截为0，伤害分别向下取整。特性仅展示，未自动模拟所有特性免伤。
